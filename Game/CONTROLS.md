# Назорати прототип

| Амал | PC | Android / Gamepad |
|---|---|---|
| Ба пеш/қафо | W/S ё тирчаҳо | Virtual joystick / чап stick |
| Ба чап/рост | A/D ё тирчаҳо | Virtual joystick / чап stick |
| Нигоҳи камера | Mouse | Touch interface / рост stick |
| Давидан | Left Shift | Default virtual joystick ё left shoulder |
| Ҷаҳидан | Space | Default virtual joystick ё gamepad bottom face |
| Миссия/ба мошин нишастан | E | Interact action / gamepad left face |
| Газ/ақиб | W/S | Чап stick |
| Рул | A/D ё тирчаҳо | Чап stick |
| Тормоз | Space | Brake action / gamepad right face |
| Камераи мошин (дур/наздик) | C | VehicleCamera action |
| Аз мошин фаромадан | E | Interact action |
| Сабти пешрафт | F5 | Танҳо mapping-и клавиатура ҳоло мавҷуд |
| Боркунии пешрафт | F9 | Танҳо mapping-и клавиатура ҳоло мавҷуд |

PC mapping-и тирчаҳо барои ҳаракати персонаж ва мошин вуҷуд дорад. Ҳассосияти камера бо `CameraSensitivity` дар хусусиятҳои Blueprint-и персонаж танзим мешавад. Android-и воқеӣ ва default virtual joystick-и муҳаррик ҳанӯз санҷигарӣ нашудаанд; амалҳои touch метавонанд дар версияи UE/дастгоҳ тағйир дода шаванд.
