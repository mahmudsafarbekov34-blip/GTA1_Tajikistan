# GTA 1 — прототипи Unreal Engine 5.4.4

Лоиҳаи C++ барои таҳияи марҳилавии як минтақаи хурди Душанбе. Ин папка аз бозии HTML/JavaScript-и сатҳи боло ҷудо аст. Лоиҳа ба дороиҳои муҳаррик ва шаклҳои муваққатии кубӣ такя мекунад; он ҳанӯз бозии пурраи GTA нест. Engine association ба UE 5.4 ва версияи охирини санҷидашаванда ба 5.4.4 таъин шудааст.

## Вазъи воқеӣ

Дар рамз барои прототип пешбинӣ шудааст:

- Қаҳрамони third-person бо WASD/тирчаҳо, давидан, ҷаҳидан ва танзими ҳассосияти камера.
- Барои қаҳрамон кубҳои Engine ҳамчун blockout-и ранга илова шудаанд; ин Skeletal Mesh ё модели иҷозатномадор нест.
- Минтақаи блокӣ бо чорроҳаҳо, замин, биноҳои ранга ва се нуқтаи расонидани бор.
- Мошини муваққатии физикӣ: нишастан/фаромадан, суръат, тормоз, гардондан, камераи берунӣ/наздик ва намоиши суръат.
- Мукофот ва рӯйхати миссияҳои иҷрошуда дар Unreal SaveGame нигоҳ дошта мешаванд.
- Харитасозии пешакии геймпад ва интерфейси стандартии virtual joystick-и UE барои touch.
- Танзимоти ибтидоии scalability ва ғайрифаъол будани Mobile HDR.

## Қисмҳои ҳанӯз сохта/тасдиқнашуда

NPC, шабу рӯз, мағоза ва гаражи харидуфурӯш, менюи тоҷикӣ, HUD-и UMG, захираи конфигуратсия/мошин, аниматсияи персонаж, моделҳои воқеии Душанбе, LOD-и санҷидашуда, бастабандии Windows/Android ва профайлкунии дастгоҳ вуҷуд надоранд. Touch joystick-и муҳаррик ҳанӯз дар дастгоҳ санҷида нашудааст. Мошин ва биноҳо танҳо блоки прототипӣ мебошанд.

## Оғоз

1. Unreal Engine **5.4.4**-ро насб карда, `GTA1_UE.uproject`-ро аз Epic Games Launcher/Unreal Editor кушоед.
2. Агар пурсад, C++ project files-ро эҷод ва модули `GTA1`-ро compile кунед.
3. Дар Editor тугмаи **Play**-ро пахш кунед. Лоиҳа бояд Entry map ва GameMode-и пешфарзро истифода барад.
4. Назоратҳо дар [CONTROLS.md](./CONTROLS.md) ва фармони идоракунӣ дар [BUILD_WINDOWS.md](./BUILD_WINDOWS.md) ва [BUILD_ANDROID.md](./BUILD_ANDROID.md) ҳастанд.

## Талаботи муҳити таҳия

- Unreal Engine 5.4.4 ва toolchain-и C++-и мувофиқ.
- Барои macOS: версияи пурраи Xcode ва SDK-и мувофиқи версияи UE.
- Барои Android: Android Studio, SDK, NDK ва JDK-и маҳз тавсияшудаи версияи UE; онро аз Project Settings / Android SDK танзим кунед.
- Барои Windows: Windows 10/11, Visual Studio бо workload-и Desktop development with C++, Windows SDK ва Unreal Engine.
- Ин компютер: Apple M1, 8 GB shared memory, тақрибан 175 GB фазои холӣ. 8 GB RAM барои UE Editor маҳдуд аст; 16 GB ё бештар тавсия мешавад.

Танҳо мавҷуд будани файлҳои scaffold маънои compile ё бозигарии тасдиқшударо надорад. Вазъи охирини санҷиш дар [TEST_REPORT.md](./TEST_REPORT.md) аст.
