# Нақшаи рушди GTA 1

## Марҳилаи 1 — муҳит ва compile

- Ҳадафи `.uproject` ба Unreal Engine 5.4.4 пайваст карда шудааст (`EngineAssociation` = `5.4`); Engine-и маҳаллӣ ҳанӯз насб нест.
- Xcode-и пурра, Android SDK/NDK/JDK ва компилятори Windows-ро барои ҳадафҳои алоҳида омода кунед.
- Project files-ро эҷод кунед, Editor target-ро compile намоед, лоиҳаро кушода PIE оғоз кунед.
- Ин марҳила то насби UE иҷронашуда аст.

## Марҳилаи 2 — қаҳрамон

- Ҳаракати пиёдагард, камера, ҷаҳиш ва stamina дар код мавҷуд аст.
- Ҳассосияти камера ҳамчун параметри Blueprint тағйирёбанда аст.
- Санҷиш дар PIE, touch HUD-и махсус, нишондиҳандаи health/stamina ва менюи танзим ҳанӯз лозиманд.

## Марҳилаи 3 — блоки Душанбе

- `AGTA1District` геометрияи оддии роҳ, чорроҳа ва биноҳоро вақти оғоз месозад.
- Маҳалла, услуби воқеии Душанбе, мағозаҳо, истгоҳҳо, NPC, навигатсия ва шабу рӯз ҳанӯз лозиманд.
- Баъд аз санҷиши collision, қисми runtime geometry-ро ба level/ISM/HISM табдил диҳед.

## Марҳилаи 4 — мошин

- `AGTA1VehiclePawn` блоки физикӣ, вуруд/баромад, throttle, steering, brake, камераи наздик/дур ва суръатро дорад.
- Танзими қувваи физика, чархҳо, gamepad, touch vehicle UI, зарари бехатар, модели иҷозатдодашуда ва гараж лозим аст.

## Марҳилаи 5 — миссияҳо

- Се нуқтаи расонидан бо мукофоти гуногун ва ID-и доимӣ сохта мешаванд.
- Матни prompt/натиҷа ҳоло debug message аст; objective UI, NPC, мусобиқа ва шаҳркашфкунӣ илова карда шаванд.

## Марҳилаи 6 — иқтисод ва SaveGame

- Мукофот, маблағ, саломатӣ, stamina, трансформ ва миссияҳои иҷрошуда дар SaveGame навишта мешаванд.
- Хариди мошин, гараж, slot/version migration, backup ва экрани Continue ҳанӯз лозиманд.

## Марҳилаи 7 — UI

- Меню, pause, settings, map, missions, garage, HUD ва локализатсияи пурраи тоҷикӣ ҳанӯз сохта нашудаанд.
- UMG/Slate ба модули лоиҳа илова ва бо Blueprint-и санҷидашуда пайваст карда шавад.

## Марҳилаи 8 — Android

- Танзимоти ғайри-Lumen/Nanite, virtual joystick-и стандартӣ ва сифати пасти ибтидоӣ гузошта шудаанд.
- Android build, touch jump/sprint/interact, LOD, memory/FPS ва санҷиши дастгоҳ талаб мекунанд SDK/NDK ва UE.

## Марҳилаи 9 — Windows

- Input-и клавиатура ва геймпади асосӣ муайян шудааст.
- Visual Studio, compile, mouse sensitivity, fullscreen/resolution/audio settings ва бастабандӣ санҷида шаванд.

## Марҳилаи 10 — санҷиш ва профайлкунӣ

- Санҷишҳои compile, PIE, ҳаракат, мошин, миссия, SaveGame ва performance дар [TEST_REPORT.md](./TEST_REPORT.md) сабт мешаванд.
- Ҳеҷ санҷиши Unreal то дастрас шудани муҳаррик иҷронашуда ҳисоб мешавад.
